## Список заданий

### Задание 1: Сравнение длины строк
Программа сравнивает длину двух строк и выводит результат сравнения.

**Пример работы:**
```
phrase_1 = 'Насколько проще было бы писать программы, если бы не заказчики'
phrase_2 = '640Кб должно хватить для любых задач. Билл Гейтс (по легенде)'

Результат: Фраза 1 длиннее фразы 2
```

### Задание 2: Проверка високосного года
Программа определяет, является ли заданный год високосным.

**Пример работы:**
```
year = 2020
Результат: Високосный год
```

### Задание 3: Определение знака зодиака
Программа запрашивает день и месяц рождения и выводит соответствующий знак зодиака.

**Пример работы:**
```
Введите день: 30
Введите месяц: Август
Результат: Ваш знак зодиака: Дева
```

### Задание 4: Подбор упаковки по размерам
Программа подбирает подходящую упаковку на основе размеров товара.

**Правила:**
- Если все измерения ≤ 15 см → "Коробка №1"
- Если хотя бы одно измерение > 200 см → "Упаковка для лыж"
- Если хотя бы одно измерение > 15 см, но < 50 см → "Коробка №2"
- В остальных случаях → "Коробка №3"

**Пример работы:**
```
width = 15, length = 55, height = 15
Результат: Коробка №3
```

### Задание 5: Счастливый билет (необязательное)
Программа проверяет, является ли шестизначный номер билета "счастливым" (сумма первых трех цифр равна сумме последних трех).

**Пример работы:**
```
number = 123321
Результат: Счастливый билет
```

### Задание 6: Вычисление площади фигур (необязательное)
Программа вычисляет площадь трех типов фигур: круг, треугольник, прямоугольник.

**Пример работы:**
```
Введите тип фигуры: Круг
Введите радиус круга: 10
Результат: Площадь круга: 314.16
```

```bash
cd <название_папки>
```

3. Запустите программу:
```bash
python python_homework.py
```
